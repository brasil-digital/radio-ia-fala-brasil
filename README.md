## 🎙️ O Projeto

Uma revolução musical brasileira: **10 artistas virtuais** criados com IA, cada um com identidade, biografia e estilo próprios — do sertanejo ao axé, do blues ao pagodão. Meta: **500 músicas originais** distribuídas nas plataformas digitais e transmitidas 24h pela Rádio IA Fala Brasil.
